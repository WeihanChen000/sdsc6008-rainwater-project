Extract all files. Open Groupwork.Rproj in RStudio. In the Console run source("RUN_ALL.R"). Base R 4.6.1 was used. Outputs appear in results and final. The reference_outputs directory contains the archived run-level results, comparisons and statistical output used in the report. The archived HKO station data can be retrieved from https://data.weather.gov.hk/weatherAPI/cis/csvfile/HKO/ALL/daily_HKO_RF_ALL.csv . Supply, backup and overflow are in cubic metres. Coverage is a percent and differences are percentage points. The page 5 comparison is in final/surface_vs_direct_2021.csv after a rerun, with an archived copy in reference_outputs/final. The capacity sweep uses paired paths and follows the main analysis as an exploratory extension. history_check.R replays 1990-2019, with 1989 available for warm-up. history_runs.csv contains paired runs; history_years.csv contains year-specific means and pointwise t intervals across demand draws. history_targets.csv counts years using unrounded 30-path means at three targets. history_weights_15m3.csv pairs years across four timing weights. The corner ANOVA residual plots and equal-variance diagnostic are in reference_outputs/final and regenerated in final.
